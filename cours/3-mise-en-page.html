Flexbox, au-delà des bases

Une dimension, le contenu d'abord

Le raccourci flex

flex regroupe trois propriétés : flex-grow (prendre la place libre), flex-shrink (rétrécir) et flex-basis (taille de départ).

ValeurÉquivaut àUsage
flex: 11 1 0%parts égales
flex: auto1 1 autoselon le contenu
flex: none0 0 autotaille figée
flex: 0 0 10remcolonne fixe
flex: 1 1 15remau moins 15rem, sinon à la ligne
  • gap espace les éléments sans marge sur les bords 2021
  • flex-wrap: wrap combiné à une flex-basis crée du responsive sans media query
  • margin-inline-start: auto pousse un élément au bout de la ligne
  • justify-content aligne sur l'axe principal, align-items sur l'axe secondaire

Trois usages de Flexbox

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  color: #1b1e3c;
}

a {
  color: inherit;
}

.site-header {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem 2rem;
  align-items: center;
  padding: 1rem 2rem;
  color: #fff;
  background: #1b1e3c;
}

.logo {
  font-weight: 800;
  text-decoration: none;
}

/* La marge automatique pousse le bouton tout à droite */
.button {
  margin-inline-start: auto;
  padding: 0.4em 1em;
  border-radius: 999px;
  font-weight: 700;
  color: #1b1e3c;
  text-decoration: none;
  background: #2ec4b6;
}

.menu {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
  margin: 0;
  padding: 0;
  list-style: none;
}

.container {
  max-width: 48rem;
  margin-inline: auto;
  padding: 2rem;
}

/* Des étiquettes qui passent à la ligne, espacées par gap */
.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 0.5rem;
  padding: 0;
  list-style: none;
}

.tags li {
  padding: 0.2em 0.8em;
  border-radius: 999px;
  background: #e2f7f4;
}

/* L'image garde sa taille, le texte prend la place restante
   et passe dessous quand il dispose de moins de 15rem */
.media {
  display: flex;
  flex-wrap: wrap;
  gap: 1.5rem;
  align-items: flex-start;
}

.media img {
  flex: 0 0 10rem;
  max-width: 100%;
  height: auto;
  border-radius: 0.5rem;
}

.media p {
  flex: 1 1 15rem;
  margin: 0;
}
  • L'en-tête passe à la ligne sur un écran étroit au lieu de déborder
  • flex: 0 0 10rem fige l'image, flex: 1 1 15rem laisse le texte s'étirer puis passer dessous
  • Aucune media query dans tout le fichier

02

Grid

Deux dimensions, la mise en page d'abord

Le vocabulaire de Grid

  • Ligne : la séparation numérotée entre deux pistes (de 1 à n + 1, ou de -1 en partant de la fin)
  • Piste : une colonne ou une rangée
  • Zone : un rectangle de cellules, nommé avec grid-template-areas
  • fr : une fraction de la place restante
  • Grille explicite : les pistes que vous déclarez. Implicite : celles que le navigateur ajoute quand des éléments débordent (taille réglée par grid-auto-rows)
FlexboxGrid
Dimensionsune (ligne ou colonne)deux à la fois
Logiquele contenu impose la taillela grille impose la place
Cas typiquemenu, étiquettes, boutonspage, galerie, programme

Les deux se combinent : une grille de cartes dont chaque carte est en Flexbox.

Zones nommées et lignes nommées

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  color: #1b1e3c;
}

/* Mobile d'abord : une colonne, zones empilées.
   Chaque ligne du dessin est suivie de sa hauteur. */
.page {
  display: grid;
  grid-template:
    "header" auto
    "main" 1fr
    "aside" auto
    "footer" auto;
  min-height: 100vh;
}

.page__header {
  grid-area: header;
  padding: 1rem 2rem;
  color: #fff;
  background: #1b1e3c;
}

.page__aside {
  grid-area: aside;
  padding: 1rem 2rem;
  background: #e2f7f4;
}

.page__footer {
  grid-area: footer;
  padding: 1rem 2rem;
  background: #f2f3f9;
}

/* Sur grand écran, on redessine les zones sans toucher au HTML */
@media (width >= 60rem) {
  .page {
    grid-template:
      "header header" auto
      "main   aside" 1fr
      "footer footer" auto
      / 1fr 18rem;
  }
}

/* Lignes nommées : une colonne de lecture centrée et
   une zone pleine largeur, dans la même grille */
.page__main {
  display: grid;
  grid-area: main;
  align-content: start;
  grid-template-columns:
    [full-start] minmax(1rem, 1fr)
    [content-start] minmax(0, 40rem)
    [content-end] minmax(1rem, 1fr)
    [full-end];
}

.page__main > * {
  grid-column: content;
}

.page__main > .full-bleed {
  grid-column: full;
  margin: 0;
}

.full-bleed img {
  display: block;
  width: 100%;
  height: auto;
}
  • grid-template dessine les zones, la hauteur de chaque rangée puis, après /, les colonnes
  • Sur grand écran, on redessine les zones sans toucher au HTML
  • Les lignes nommées [content-start]… créent une colonne de lecture et une image pleine largeur dans la même grille
  • grid-column: content vise les lignes content-start à content-end

auto-fill, dense et subgrid

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  color: #1b1e3c;
}

.container {
  max-width: 72rem;
  margin-inline: auto;
  padding: 2rem;
}

/* Autant de colonnes de 15rem minimum que la place le permet,
   sans media query. dense comble les trous laissés. */
.program {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(15rem, 1fr));
  grid-auto-flow: dense;
  gap: 1.5rem;
  margin: 0;
  padding: 0;
  list-style: none;
}

/* Chaque carte occupe 3 lignes de la grille parente et
   reprend ses pistes : titres, textes et méta s'alignent
   d'une carte à l'autre */
.concert {
  display: grid;
  grid-row: span 3;
  grid-template-rows: subgrid;
  gap: 0.5rem;
  padding: 1rem;
  border: 2px solid #d9dcea;
  border-radius: 1rem;
}

.concert h2,
.concert p {
  margin: 0;
}

.concert__meta {
  align-self: end;
  font-weight: 700;
  color: #0b7a70;
}

/* Les têtes d'affiche prennent deux colonnes */
.concert--featured {
  grid-column: span 2;
  border-color: #2ec4b6;
  background: #e2f7f4;
}

/* Sur une seule colonne, span 2 créerait une colonne
   implicite : on l'annule */
@media (width < 34rem) {
  .concert--featured {
    grid-column: auto;
  }
}
  • repeat(auto-fill, minmax(15rem, 1fr)) : autant de colonnes que la place le permet
  • grid-auto-flow: dense remonte les petites cartes dans les trous. L'ordre visuel s'écarte alors du HTML : à réserver aux contenus sans ordre de lecture
  • subgrid : la carte reprend les rangées de la grille parente, ses trois blocs s'alignent avec ceux des voisines 2023

03

Les container queries

Un composant qui s'adapte à sa place, pas à l'écran

Media query ou container query ?

@media (width >= 50rem)

Interroge la taille de la fenêtre. Une carte placée dans une colonne étroite d'un grand écran se croit sur un grand écran.

@container (width > 30rem)

Interroge la taille de son conteneur. La même carte s'adapte à la colonne qui l'accueille : un vrai composant réutilisable. Baseline 2023
  • Le parent se déclare conteneur : container-type: inline-size (ou le raccourci container: nom / inline-size)
  • Unités relatives au conteneur : cqi (1 % de sa largeur), cqb (de sa hauteur)
  • Un élément ne peut pas interroger sa propre taille, seulement celle d'un ancêtre

La carte interroge sa zone

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  color: #1b1e3c;
}

.layout {
  display: grid;
  gap: 2rem;
  padding: 2rem;
}

@media (width >= 50rem) {
  .layout {
    grid-template-columns: 2fr 1fr;
  }
}

/* Chaque zone devient un conteneur interrogeable
   sur sa largeur (axe inline) */
.card-zone {
  container: card-zone / inline-size;
}

/* La même carte, empilée par défaut */
.artist-card {
  display: grid;
  overflow: hidden;
  border: 2px solid #d9dcea;
  border-radius: 1rem;
}

.artist-card img {
  width: 100%;
  height: auto;
  aspect-ratio: 4 / 3;
  object-fit: cover;
}

.artist-card__body {
  padding: 1rem;
}

.artist-card h2 {
  margin: 0;

  /* 1cqi = 1 % de la largeur du conteneur */
  font-size: clamp(1.25rem, 5cqi, 2.5rem);
}

/* Quand SA zone dépasse 30rem, la carte passe à l'horizontale,
   quelle que soit la taille de l'écran */
@container card-zone (width > 30rem) {
  .artist-card {
    grid-template-columns: 2fr 3fr;
    align-items: center;
  }

  .artist-card img {
    height: 100%;
    aspect-ratio: auto;
  }
}
  • container: card-zone / inline-size nomme le conteneur et l'interroge sur sa largeur
  • Dans la grande zone, la carte passe à l'horizontale. Dans l'encart, elle reste empilée, sur le même écran
  • Le titre suit la largeur de la carte grâce à 5cqi, borné par clamp()

Mini-exercice : la bonne requête

Media query ou container query ?

Pour chaque besoin, choisissez avec votre voisin et justifiez :

  1. Le menu passe en bouton « burger » sur téléphone
  2. Une carte produit s'affiche dans une grille, un carrousel et une barre latérale
  3. La page passe de une à deux colonnes
  4. Un tableau de prix réduit ses colonnes quand il est placé dans une modale
  5. Les animations sont coupées pour l'utilisateur qui le demande
Réponses : 1 media (la page entière), 2 container, 3 media, 4 container, 5 media (prefers-reduced-motion n'est pas une question de taille).
04

Fluide et intrinsèque

Moins de points de rupture, plus de règles qui s'adaptent

Une typographie fluide avec clamp()

clamp(min, préférée, max) : la valeur préférée suit la fenêtre, sans jamais sortir des bornes.

Exemple : clamp(2rem, 1.2rem + 4vw, 4.5rem)

  • 2rem : la taille minimale, sur un petit écran
  • 1.2rem + 4vw : la valeur préférée, qui grandit avec la fenêtre
  • 4.5rem : la taille maximale, sur un grand écran

Générateur d'échelles : Utopia.

  • Une taille en vw seul ne grossit pas avec le zoom du navigateur : c'est un défaut d'accessibilité (WCAG 1.4.4)
  • rem + vw garde une part sensible au zoom
  • Les mêmes échelles servent aux espacements : marges et gouttières respirent sur grand écran

Un bandeau fluide

/* Échelle fluide : minimum, valeur préférée, maximum.
   La partie en rem garde le zoom du navigateur efficace. */
:root {
  --step-0: clamp(1rem, 0.9rem + 0.5vw, 1.25rem);
  --step-3: clamp(2rem, 1.2rem + 4vw, 4.5rem);
  --space-m: clamp(1rem, 0.6rem + 2vw, 2.5rem);
}

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  font-size: var(--step-0);
  line-height: 1.5;
}

/* Un bandeau au ratio fixe, image en fond qui ne se
   déforme jamais */
.hero {
  position: relative;
  display: grid;
  align-items: end;
  aspect-ratio: 16 / 9;
  max-block-size: 90vh;
  color: #fff;
}

.hero__image {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  object-fit: cover;
}

/* Propriétés logiques : « inline » suit le sens de lecture,
   « block » l'empilement. Elles s'adaptent à l'arabe ou
   au japonais vertical sans rien réécrire. */
.hero__content {
  position: relative;
  max-inline-size: 40rem;
  padding-block: var(--space-m);
  padding-inline: var(--space-m);
  background: linear-gradient(to top, #1b1e3ccc, transparent);
}

.hero h1 {
  margin-block: 0 var(--space-m);
  font-size: var(--step-3);
  line-height: 1.1;
}

.hero__dates {
  margin-block: 0 0.5rem;
  font-weight: 700;
}

.hero__cta {
  display: inline-block;
  padding-block: 0.6em;
  padding-inline: 1.2em;
  border-radius: 999px;
  font-weight: 700;
  color: #1b1e3c;
  text-decoration: none;
  background: #2ec4b6;
}
  • Trois variables d'échelle, réutilisées partout
  • aspect-ratio réserve la place du bandeau avant le chargement de l'image 2021
  • object-fit: cover recadre l'image au lieu de la déformer
  • Propriétés logiques : inset, padding-inline, max-inline-size

La mise en page intrinsèque

/* Des mises en page qui s'adaptent à leur contenu et à la
   place disponible, sans aucune media query */
body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.5;
  color: #1b1e3c;
}

.container {
  max-width: 60rem;
  margin-inline: auto;
  padding: 2rem;
}

/* Stack : un espacement régulier entre enfants */
.stack {
  display: flex;
  flex-direction: column;
  gap: 1rem;
}

.stack > * {
  margin-block: 0;
}

/* Cluster : des éléments de largeur variable qui passent
   à la ligne */
.cluster {
  display: flex;
  flex-wrap: wrap;
  gap: 0.5rem 1rem;
  margin: 0;
  padding: 0;
  list-style: none;
}

/* Sidebar : la barre garde 12rem, le contenu prend le reste
   et passe dessous s'il descend sous 50 % de la largeur */
.with-sidebar {
  display: flex;
  flex-wrap: wrap;
  gap: 2rem;
}

.with-sidebar > .sidebar {
  flex-basis: 12rem;
  flex-grow: 1;
}

.with-sidebar > :last-child {
  flex-basis: 0;
  flex-grow: 999;
  min-inline-size: 50%;
}

/* Switcher : tout sur une ligne au-delà de 40rem, tout
   empilé en dessous, jamais d'état intermédiaire */
.switcher {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}

.switcher > * {
  flex-basis: calc((40rem - 100%) * 999);
  flex-grow: 1;
}

.box {
  margin: 0;
  padding: 1rem;
  border: 2px solid #d9dcea;
  border-radius: 0.75rem;
}

  • Les zones nommées rendent la mise en page lisible et facile à redessiner

  • Les container queries font des composants vraiment réutilisables
  • clamp() et les motifs intrinsèques remplacent la plupart des points de rupture
