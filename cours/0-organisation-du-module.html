Le module

Organisation du module

HTML et CSS, encore ? Oui, mais en 2026

Ce que l'IA fait bien

Une page qui « a l'air juste » en quelques secondes : des div, des marges au hasard, des classes utilitaires empilées

Ce qu'on attend de vous

Une page juste : sémantique, accessible au clavier et au lecteur d'écran, fidèle à la maquette, rapide, maintenable

Ce que vous allez prouver

Avec des outils : comparaison visuelle automatisée, audits d'accessibilité et de performance, intégration continue
  • Le CSS a plus changé depuis 2022 qu'en dix ans : couches, :has(), container queries, nesting, anchor positioning, View Transitions
  • Ces nouveautés sont récentes. L'IA les connaît mal et vous les rencontrerez dans les projets que vous reprendrez
Demander qui a déjà utilisé Sass, intégré une maquette Figma, testé un site au lecteur d'écran.

Objectifs du module

À la fin du module, vous serez capables de :

  • Écrire un HTML sémantique et accessible, vérifié au clavier, au lecteur d'écran et avec axe DevTools, et optimisé pour le référencement
  • Maîtriser la cascade moderne et les mises en page actuelles : couches, sélecteurs avancés, Grid, Flexbox, container queries
  • Écrire et compiler du Sass moderne organisé autour de design tokens
  • Intégrer fidèlement une maquette Figma et le prouver par des tests automatisés
  • Construire les composants d'un framework CSS en JavaScript natif et en Web Components

Programme

Cours 1 · HTML

Sémantique, formulaires, accessibilité (WCAG 2.2, RGAA), SEO technique

Cours 2 · Cascade

Couches, spécificité, sélecteurs avancés, nesting, custom properties, couleurs modernes

Cours 3 · Mise en page

Grid et subgrid, Flexbox, container queries, typographie fluide

Cours 4 · Sass et qualité

Sass moderne, design tokens, architecture d'un framework, Stylelint, Playwright, GitHub Actions

Cours 5 · Composants

JavaScript natif, dialog, Popover, Web Components, View Transitions, performance

Pratique

Deux TP individuels corrigés, un projet en groupe et trois Kahoot
Environ 30 % de théorie. Chaque notion est montrée sur une démo complète, en ligne, puis appliquée le jour même.

Le projet

Organisation du module

Votre propre framework CSS, en groupe

  • Par groupes de 3 (deux binômes pour une classe de 22)
  • Vous créez un mini-framework CSS : design tokens, Sass organisé en couches, composants documentés et accessibles
  • Avec lui, vous intégrez 3 pages d'une maquette choisie sur Figma Community
  • La qualité est prouvée par des outils en intégration continue : Stylelint, html-validate, comparaison visuelle Playwright, Lighthouse et axe
  • Le site est déployé sur GitHub Pages
  • Le sujet complet et la grille sont sur le site du module
Le syllabus parle de jQuery. Je le remplace par le JavaScript natif et les Web Components, standards du navigateur que vous retrouverez sous React.

Dès ce lundi midi

  1. Formez votre groupe et choisissez une maquette dans la liste du sujet (une maquette par groupe, premier arrivé, premier servi)
  2. Un membre crée le dépôt GitHub à partir du dépôt modèle, puis invite les autres membres et Chris-CHEVALIER
  3. Chacun se répartit le travail et l'indique dans le README : chacun écrit une part réelle du framework et des pages
Les rendus ne passent pas par e-mail. L'invitation au dépôt suffit : je corrige le dernier commit poussé sur main le 13 décembre avant 23h59.

Règle ESGI : 50 % de contrôle continu et 50 % d'examen. Deux notes saisies sur MyGES, qui leur donne le même poids.

Le jeudi 10 décembre

Écrit individuel · 45 min

  • 20 questions à réponse courte sur les cinq cours, 1 point chacune
  • Expliquer, comparer, justifier : quelques phrases par question, aucun code à écrire
  • Sur Microsoft Forms avec votre compte de l'école, sans IA ni documentation

Soutenance · 10 min par groupe

  • Démonstration : chacun présente ce qu'il a réalisé
  • Un extrait de votre code, que je choisis, à expliquer
  • Une question sur le travail d'un autre membre
La production du groupe est notée sur une grille de 20 critères, dont une partie vérifiée par script. Un membre qui n'a pas contribué peut voir sa note réduite, jusqu'à 0.

L'IA générative : autorisée en projet, pas à l'écrit

  • ChatGPT, Claude, Copilot… sont autorisés pour les TP et le projet
  • Vous devez comprendre votre code de bout en bout et pouvoir l'expliquer en soutenance
  • Déclarez votre usage dans le README : quels outils, pour quoi faire
  • Une fonctionnalité non expliquée n'est pas comptée
  • L'écrit se fait sans IA : il vérifie que vous avez compris ce que vous avez codé en TP et en projet
  • Le plagiat et la triche entraînent un 0 à l'épreuve concernée
Conseil : utilisez l'IA comme un tuteur (expliquer une règle, relire votre code), pas comme un auteur.

Avant de commencer : le test de positionnement

  • 12 questions, anonymes et non notées, pour que j'adapte le cours à votre niveau
  • Répondez seuls, sans aide ni IA. « Je ne sais pas » est une réponse utile
  • Nous corrigeons ensemble à partir des résultats de la classe
